# Ghost Ship

Ghost Ship was a Hack Club Halloween event for both Hack Clubs and teenagers! You built a spooky game in p5.js, alone or at a club meeting, and submitted it to get $5 of Halloween candy and a sticker sheet.

This site still has a step-by-step guide that you can use to build a game in p5.js!
The site was built with SvelteKit and p5.js.

Submissions are now closed. Sponsored by Jared, run by CK. Look out for more events soon!

Check it out at [ghostship.hackclub.com](https://ghostship.hackclub.com).
